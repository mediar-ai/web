# Mediar dashboard


Browser Workflow Capture App

A Next.js application for capturing, analyzing, and executing browser workflows with AI.
 
## Features

- **Workflow Dashboard** - View and manage automated workflows
- **Workflow Deployment** - Deploy workflows to production environments  
- **Workflow Execution** - Execute workflows with parameter substitution
- **Web Workflow Recorder** - Record browser interactions for automation

## Tech Stack

- **Frontend**: Next.js 15, React 19, TypeScript, Tailwind CSS
- **Backend**: Supabase, Modal (serverless)
- **AI**: Google Vertex AI, Gemini models
- **Authentication**: Clerk

## Getting Started

```bash
# Install dependencies
npm install

# Run development server
npm run dev
```
